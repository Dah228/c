# IELTS Practice

Статический сайт для подготовки к IELTS Academic. На странице собраны официальные бесплатные демоверсии Listening, Reading, Writing и Speaking, а также критерии оценки. Пробники, аудио и ключи открываются на сайтах IELTS и British Council.

## Опубликовать на GitHub Pages

1. Распакуй архив. Создай репозиторий GitHub, например `ielts-practice`.
2. Загрузи в корень репозитория содержимое архива. `index.html` и папка `vendor` должны быть рядом. Если используешь веб-загрузку GitHub, можно перетащить одновременно файлы и папку `vendor`. Файл `.nojekyll` тоже есть в архиве.
3. В репозитории открой **Settings → Pages → Build and deployment**. Выбери **Deploy from a branch → main → /(root)** и нажми **Save**.
4. После публикации в **Settings → Pages** появится ссылка. Открой её на телефоне.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Запустить локально

Из папки с `index.html` запусти `python3 -m http.server 8000` и открой [localhost:8000](http://localhost:8000). Для модулей JavaScript и PDF нужен HTTP-доступ. На GitHub Pages дополнительные настройки, установка пакетов и ключи API не нужны.

## Импорт словаря

Тренажёр читает текстовые PDF и документы DOCX, в том числе таблицы Word. Скан PDF сначала нужно распознать, чтобы в нём появился выделяемый текст. Если строки разобрались неровно, открой редактор под кнопкой загрузки.

Удобные форматы:

```text
fluent | свободно говорящий | After a year abroad, she became fluent in English.
to submit | подавать заявку | We can submit the form online.
take notes | делать заметки | We can take notes during the lecture. | verb
choose | выбирать | We can choose the next topic. | verb | chose | chosen
```

Можно импортировать список английских слов без примеров. Тренажёр ищет определения и примеры в словаре WordNet. Если у слова нет примера, используется перевод или определение. Для выражений без подсказки предлагается повторение с показом ответа. Добавь своё предложение для упражнения с контекстом.

Во вкладке **Вписать форму** нужно ввести часть предложения, заменяющую пропуск. Время указано над заданием. Чтобы включить глагол, который сайт определил как другую часть речи, добавь `to` перед ним или `| verb` после примера. Для редких форм после `verb` можно указать V2 и V3. Используй короткий пример вроде `We can choose the next topic.`, чтобы движок мог сохранить дополнение при смене времени.

Обработка файлов выполняется в браузере. Текст последнего словаря сохраняется в этом браузере, если он разрешает локальное хранение. Ограничения импорта — 15 МБ, 80 страниц PDF и до 400 слов или выражений.

## Зависимости

Локальные копии PDF.js 4.10.38, fflate 0.8.2, Compromise 14.14.4 и словарь на основе WordNet 3.1. Тексты лицензий находятся в `vendor`.
